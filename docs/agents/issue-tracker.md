# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues in `thebigthing313/njmca-members`.

## Conventions

- Create issues in GitHub Issues.
- Apply the `needs-triage` label to newly published PRDs or newly captured work unless the user says otherwise.
- Read existing issues and comments before updating or splitting related work.
- Keep PRD issues focused on product intent and implementation decisions; use follow-up implementation issues for independently grabbable slices.

## When a skill says "publish to the issue tracker"

Create a GitHub issue in `thebigthing313/njmca-members`.

## When a skill says "fetch the relevant ticket"

Fetch the GitHub issue by number from `thebigthing313/njmca-members`, including its labels and comments.
